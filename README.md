# Highly Available and Self-Healing Web Application on AWS Using DevOps Practices

## Project Overview
This project focuses on designing and deploying a highly available and self-healing web application using AWS Cloud Services and DevOps tools.

The application is designed to provide reliable access, handle incoming traffic, and recover automatically from infrastructure failures.

## Project Objectives
- Build a highly available web application.
- Deploy the application on AWS EC2.
- Distribute incoming traffic using an Application Load Balancer.
- Configure Auto Scaling for handling changing workloads.
- Use Docker for application containerization.
- Implement CI/CD using Jenkins.
- Automate infrastructure provisioning using Terraform.
- Monitor application health using Amazon CloudWatch.
- Configure SNS notifications for alerts.

## Architecture Overview

The application uses AWS infrastructure to provide high availability, traffic distribution, monitoring, and recovery

**Architecture Flow:**

User → Application Load Balancer → Target Group → EC2 Instances → Docker Container → Web Application

Supporting services:
- Auto Scaling
- CloudWatch
- SNS
- RDS
- S3
- Jenkins
- Terraform

## Key Features

- High availability using AWS infrastructure.
- Load balancing for incoming web traffic.
- Automatic scaling based on workload.
- Docker-based application deployment.
- CI/CD pipeline using Jenkins.
- Infrastructure automation using Terraform.
